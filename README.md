# Frontend - WR602D

Frontend du jeu de roulette 3D développé en Three.js avec gestion de mises, animations et scores.

## 🔧 Installation

```bash
git clone https://github.com/YanisKujo/Front-WR602D.git
cd Front-WR602D
npm install
npm run dev
```

## 🎮 Fonctionnalités

- Roue de roulette 3D réaliste
- Gestion des crédits et mises
- Interface responsive
- Authentification JWT (via localStorage)
- Classement mondial

## 📦 Technologies

- Three.js
- Vite
- Axios
- CSS
```
